Membrane

Preview what a new memory will make your agent do. All data is synthetic; refund tools are simulated.

1. Propose a memory

A source arrives, a memory is proposed from it, and Membrane stages it. A staged memory is invisible to the live agent.

2. Behavior preview

The same frozen tasks run twice in fresh sessions: View A uses current memory, View B adds the candidate. We compare the tool calls, not the wording.

No candidate staged yet.

3. Live agent check

Run the live agent, with active memory only, on any frozen task. Use it after accepting, expiring or revoking a memory to see the effect.

4. Memory ledger

Every version, its scope, expiry and status. Nothing is overwritten or deleted.
